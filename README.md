# Multi-Type Proximity Clustering

This project demonstrates clustering analysis using multiple proximity and distance metrics for different data types in Python.

## Overview

The project applies clustering techniques on:

- Nominal data
- Binary data
- Ordinal named data
- Cardinal numerical data
- Mixed-type datasets

Different proximity metrics are used depending on the nature of the dataset.

## Methods Used

- Hamming Distance
- Jaccard Distance
- Euclidean Distance
- Gower Distance
- K-Means Clustering
- PCA Visualization

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- OpenPyXL
- Matplotlib
- Seaborn

## Project Outputs

The project generates:

- Distance matrices
- Cluster assignments
- PCA cluster visualizations
- Excel reports with clustering results
